# Scribdown 设计资产

`design/` 目录只保留设计资产与源文件，不再承担文档站入口职责。所有可浏览的规范、视觉基线、样例和执行手册统一收敛到 `apps/docs/`。

## 目录结构

| 分类 | 文件 | 内容 |
| --- | --- | --- |
| 设计源文件 | [source/scribdown-ui.pen](./source/scribdown-ui.pen) | Scribdown 主设计稿 |
| 过程草稿 | [source/step.pen](./source/step.pen) | 分步出图或过程性画板 |
| 导出图 | [source/renderings.png](./source/renderings.png) | 设计导出预览图 |
