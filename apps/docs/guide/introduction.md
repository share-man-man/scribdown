# 产品介绍

Scribdown 是一个以**手绘风格**为核心视觉语言的 Markdown 渲染器，可作为浏览器插件与 VS Code 插件运行，为 Markdown 内容提供统一、安全、差异化的阅读体验。

## 产品定位

| 维度 | 说明 |
| --- | --- |
| 阅读体验 | 稳定、清晰地呈现 Markdown 内容，兼顾可读性与视觉表现 |
| 多端一致 | 浏览器插件与 VS Code 插件共用同一渲染核心，壳层行为差异不影响正文规则 |
| 手绘风格 | 纸感纹理、手绘线条、低饱和配色、克制动效——在保证阅读效率的前提下构建差异化体验 |
| 安全默认 | 原始 HTML 经双层清洗，外链与不可信资源失败时稳定降级 |

## 适用场景

- 浏览器中的 Markdown 预览
- VS Code 中的 Markdown 预览
- 需要统一视觉语言和安全渲染策略的宿主环境

## 支持平台

- **浏览器插件**：Chrome、Edge、Firefox（基于 WebExtension API）
- **编辑器插件**：VS Code Extension（Webview 预览容器）

## 核心能力

- Markdown 文档渲染
- Markdown 节点的视觉表达与交互反馈
- 主题、字体、密度等渲染层配置
- 安全渲染与异常状态降级
