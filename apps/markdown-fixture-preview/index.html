@scribdown/markdown-renderer

第三方接入示例

三个 API + 一个根类，把 Markdown 渲染成右侧的样子。左侧 Quickstart 可直接复制。

1. 安装

pnpm add @scribdown/markdown-renderer

2. HTML 容器

容器必须带类名 scribdown-markdown，视觉 token 都挂在它上面。 

<article id="md" class="scribdown-markdown"></article>

3. JS 接入

import {
  renderMarkdown,
  hydrateMarkdown,
  mountMarkdownToolbar
} from "@scribdown/markdown-renderer";
import "@scribdown/markdown-renderer/styles.css";

const root = document.getElementById("md")!;
root.innerHTML = await renderMarkdown(markdownText);
hydrateMarkdown(root);
mountMarkdownToolbar(document.body);

API 一览

API 必需 作用
renderMarkdown(md) ✅ Markdown → 已 sanitize 的 HTML 字符串
hydrateMarkdown(root) 推荐 图片放大、代码复制、Mermaid 等运行时交互
mountMarkdownToolbar(c) 可选 浮动工具栏：回到顶部 / 目录 / 内容宽度
