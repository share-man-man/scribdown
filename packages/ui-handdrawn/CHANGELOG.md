# @scribdown/ui-handdrawn

## 0.2.2

### Patch Changes

- 1757947: Scribdown 界面新增繁体中文、日语、韩语、西班牙语、法语、德语、巴西葡萄牙语与俄语支持。语言选择器仅展示显式语言，未设置偏好时自动跟随宿主应用语言；同时修复多语言列表的视口适配、光标状态与开合动画。
- 35e7035: 优化代码块手绘边框与语言标签的拼接效果，修复边框纹理对齐和标签右侧笔画裁切问题。

## 0.2.1

### Patch Changes
